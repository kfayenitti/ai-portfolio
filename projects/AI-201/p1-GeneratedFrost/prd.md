## What I'm Building

I am using ai-generated code and generative AI in ComfyUI to take a VFX project from concept to final product in Houdini. The final outcome will be an AI code-generated frost model, with lighting and compositing assisted with generative AI. Artists that use this workflow and tools will be able to streamline the process and technology using AI.


## Done Criteria (M4 Target)

- [ ] The Houdini VEX tool generates a controllable, art-directed frost/branch structure from user-set parameters.
- [ ] The Houdini VEX tool does not break and generates consistent results
- [ ] ComfyUI is set up to effectively create iterations based on user input 
- [ ] The final submission includes an artist-made render and comp (no AI-generated final image).

## Technical Constraints

- Environment: Houdini and Nuke pipeline with ComfyUI and ClaudeAI assistance
- Input: Directions for Claude code to generate VEX. Playblasts / renders for iterations
- Output: Final image rendered out of Houdini, created with AI assistance but no final untouched generated imagery.
- Tools I'm exploring: Houdini VEX, Claude, ComfyUI, and Nuke.

## Out of Scope

- Not building: An overarching tool to implement AI in Houdini
- Not building: A one-click, on demand generation of a simulation. This is a tool that must be used and directed
- Not building: AI-generated final renders as deliverables.
- Saving for capstone: Final render of VFX image

## Connection to Quarter Question

This project explores how AI-assisted code and AI-supported visual ideation can enhance VFX workflow development while preserving artist control over final outputs.
